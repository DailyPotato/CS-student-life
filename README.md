# 计算机学生模拟人生 · CS LIFE

从 Hello World 到毕业答辩，一款中文校园文字养成游戏。为 GitHub Pages 制作，原生 HTML / CSS / JavaScript，无第三方运行依赖，无后端，无 API 密钥。

游戏地址：**https://dailypotato.github.io/CS-student-life/**。

## 开始游戏

直接打开 `index.html` 即可游玩。也可以安装 Node.js 后运行 `node server.cjs`，访问输出的本机地址。

- 8 个学期，每学期用 4 个关键周推进；每周安排 3 项行动。
- 3 种家庭背景、36 项天赋。每次开局按稀有度随机抽出 8 项，从中选择 2 项；可重抽 2 次，重抽不会清空姓名与家庭背景。
- 天赋可影响初始属性、行动收益、每周恢复、生活开销、属性检定与竞赛概率，组合会产生不同的开局体验。
- 23 项行动，涵盖课程、编程、算法、项目、科研、竞赛、实习、毕业设计、路线准备、道具与连续故事。
- 63 个原创校园事件（含 9 个路线专属事件、4 条连续故事和物品/设备事件），按年级、角色属性、发展路线和经历筛选，并根据属性加权随机出现；优先出现本局尚未遇到的合适事件。
- 编程、算法、科研、人脉等会影响遇到的机会；低健康、低心态与资金不足也会改变事件池。有属性检定的选项显示成功率与成败后果，并提供不需属性门槛或支出的安全选择。
- 保研、考研、就业三条可选路线，分别记录准备、评审与录取结果；未选择路线时保留原有 11 种自由探索结局。另有 10 项可跨周目收集的成就。
- 每次操作后在当前浏览器自动存档，支持 JSON 导出、校验后导入。
- 学业面板显示课程掌握、项目、论文、实习与毕设的实时进度；预计 GPA 可展开查看各项贡献。最近一周成长显示结算后的真实属性增减，事件另行展示结果。
- 校园商店有 10 件道具，生活费可以换取书籍、设备、耗材与活动机会。背包、持续状态、长期伙伴和故事记录随存档保存。
- 支持手机、平板、电脑；不加载外部字体、图片、统计或广告。

毕业要求为至少 152 学分和 100% 毕业设计进度。期末 GPA 低于 2.0 留下一门补考，补考可追回 8 学分。大四记得在「学习」中安排毕业设计。

## 校园商店与生活故事

所有购买均使用游戏内生活费。在安排周计划时可购买、使用道具，不占行动次数；研读书籍、参加交流、推进故事仍占每周 3 次行动中的一格。购买会保留已安排行动所需的预算，永久道具不能重复购买，消耗品有背包上限。

| 道具 | 价格 | 用途 |
| --- | --- | --- |
| 算法书 | ¥360 | 解锁研读算法书；算法刷题额外 +3 算法 |
| 系统教材 | ¥320 | 上课额外 +2 理论；考研复习额外 +3 进度 |
| 电脑升级 | ¥1,800 | 项目额外 +10 进度；编程练习额外 +2 编程 |
| 降噪耳机 | ¥420 | 编程、考研复习各少消耗 2 心态 |
| 跑鞋 | ¥280 | 夜跑额外恢复 4 健康 |
| 咖啡 | ¥60 | 心态 +5、健康 -2；未来 2 周编程练习 +3、算法刷题 +2 |
| 营养餐包 | ¥100 | 使用后健康 +12、心态 +5 |
| 云计算额度 | ¥240 | 未来 2 周项目额外 +12 进度、科研额外 +8 论文进度 |
| 学术交流票 | ¥500 | 安排一次交流行动后消耗，结识长期学术伙伴 |
| 维修工具包 | ¥200 | 使用后解除电脑故障，也能在故障事件里使用 |

临时效果在使用后的两次周行动结算中生效，每次结算后扣一周；处理事件、进入新学期或读取存档不会额外扣时长。同类效果尚未结束时不能叠加使用。电脑故障会暂停个人项目开发，可以用钱维修，也可以花一次行动借用学校设备。

随机事件还会开启有后续的故事：

- 开发委托：先拿 ¥120 前期费用，3 周内完成 2 次委托开发。交付后收 ¥650 尾款，获得长期客户信任，兼职收入增加。
- 开源贡献：4 周内完成 2 次贡献，再处理评审。合入后留下维护者联系，改善编程检定和校招评价。
- 固定共学：3 周内完成 2 次共学，建立学习搭档，继续解锁小组行动并提高课程、复习效率。
- 校园产品：投入 ¥200，4 周内完成 3 次项目开发。发布后获得试运营补助和第一批用户，影响之后的项目与校招。

故事达成目标或到达截止周时，后续事件优先出现；多个后续按截止时间先后处理。到期后不能继续补推进，但按时完成的任务可以等待后续结算。未达目标仍可免费结束故事，记录会保留；每条故事只能体验一次，不会反复发放报酬。大学篇结束时，尚未结算的故事会留下未完成记录。

交流伙伴为保研、复试各加 3 分；维护者联系与校园用户各为校招加 3 分，长期效果会显示在背包与校园故事中。旧存档自动补全这些字段，不会凭空获得物品或奖励。

## 毕业去向

可以从入学起选择方向，大三起在「去向」行动分类中准备。每项准备进度上限为 100，与原有能力、成果共同影响阶段评分。所有节点都在对应周的校园事件处理后自动结算，结果随存档保存，不会重考或因之后的属性变化重算。

| 路线 | 节点 | 必要条件 | 评分来源与通过线 |
| --- | --- | --- | --- |
| 保研 | 大四上第 2 周 | 前六学期 GPA ≥ 3.50，无待补考课程，论文或竞赛成果至少 1 项，保研准备 ≥ 60 | 申请准备 40%、科研 20%、面试准备 15%、人脉 5%、前六学期 GPA × 5；通过线 70 |
| 考研初试 | 大四上第 4 周 | 初试复习 ≥ 60 | 复习 55%、理论 25%、算法 15%、心态 5%；通过线 65 |
| 考研复试 | 大四下第 2 周 | 初试通过，面试准备 ≥ 40 | 初试成绩 25%、面试准备 40%、编程 15%、科研 10%、人脉 10%；通过线 60 |
| 就业 | 大四下第 3 周 | 求职准备 ≥ 60，编程 ≥ 40，已完成项目 ≥ 1 | 求职准备 30%、面试准备 25%、编程 20%、算法 10%、人脉 5%、项目与实习各至多 5 分；通过线 60 |

满足必要条件后，各项评分有 ±6 分的随机波动，限制在 0–100 分；页面实时显示预估区间。就业的项目加分在 3 个项目时达到上限，实习加分在 2 段完整经历时达到上限。准备行动还会获得能力收益：科研与人脉提高保研准备效率，理论提高复习效率，项目提高求职准备效率，人脉提高模拟面试效率。

在本周计划为空、且目标路线尚未截止时可以切换方向，也可暂回自由探索。切换保留所有准备进度与阶段记录；已失败的节点不能重考，已成功的去向可以切回。保研未通过后仍可抓紧准备考研或就业；考研未录取后可在校招截止前转向就业。录取或录用意向不代替毕业所需的学分和毕设。

旧存档自动补全路线字段，默认保持自由探索；尚未到期的路线可以直接参与，已经过去的阶段不会追溯补发结果。这里的分数、资格和节点均是游戏简化设定，不对应现实院校或企业的规则。

课程掌握是本学期的学习进度，进入下一学期归零；理论基础是长期能力，不随学期重置。每 20 点理论让一次认真上课多获得 1 点课程掌握，理论本身也影响期末成绩及科研资格。人脉影响沟通检定和相关事件、每点增加竞赛获奖率 0.1 个百分点（总概率上限 90%）；每 25 点人脉使一次科研多推进 2 点论文进度。项目与论文进度达到 100 后结算一项成果并保留溢出进度；科研达到 60 时，每次科研额外推进 5 点论文进度。

存档仅存于当前网址的浏览器本地空间。从本机切换到 github.io、换设备或清理网站数据前，请导出备份。成就收藏也仅保存在本机，导入存档会合并该局已有成就。浏览器不支持本地存储时，仍可游玩并导出进度。

## 发布到 GitHub Pages

目标仓库：`DailyPotato/CS-student-life`。

1. 在 GitHub 创建上述仓库。若使用 GitHub 免费个人账户，请使用公开仓库。
2. 将本文件所在目录的内容上传到仓库根目录，保留 `.github/workflows/pages.yml`，主分支使用 `main`。
3. 进入仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 在 **Actions** 中运行 **Test and deploy to GitHub Pages**；以后推送 `main` 会自动测试并重新发布。
5. 等部署成功后，打开页面上显示的地址。预期为 `https://dailypotato.github.io/CS-student-life/`。

也可在 Pages 中选择 **Deploy from a branch → main → / (root)**，直接发布根目录的静态文件，不需要构建。此模式下可以禁用上述 Actions 发布工作流，避免并行部署。

所有资源使用相对路径，兼容项目子路径 `/CS-student-life/` 与个人主页根路径。

## 开发与验证

```text
node --test tests/engine.test.cjs
node --check app.js
node server.cjs
```

- `data.js`：课程、角色背景、天赋、行动、事件、成就配置。
- `engine.js`：与界面独立的状态机、结算、存档校验和结局规则。
- `app.js`：界面、对话框、本地存档、导入导出与渐进式 WebMCP 支持。
- `style.css`：响应式界面。
- `tests/engine.test.cjs`：行动约束、时序、存档恢复、学期结算、补考、成果与完整四年流程。

不使用网络 API，随机数状态随存档一起保存。继续同一存档会保持后续随机结果。属性检定成功率为 `55% + (当前属性 - 难度) × 0.8% + 天赋加成`，限制在 10%–95% 之间；不保证高属性必定成功。旧版存档可以继续使用，不会在读取时重复获得开局天赋收益。游戏数值是简化模型，不代表真实成绩、招聘结果或个人价值。

## 创作说明

玩法方向来自用户提出的「数学系学生模拟」「医学生模拟」这类文字养成游戏：属性成长、分支事件与多结局。调研时参考了公开的相关医学生模拟项目 [学医这一生](https://github.com/K1NGzh/xueyi-yisheng) 的题材组织方式；未复用其源码、素材或事件文案。用户所指的数学系原作仓库未能确认，因此本作不声称复刻某个特定原作。

本作的界面、事件文案和游戏逻辑均为本项目新编写。
